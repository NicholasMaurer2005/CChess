# CChess
This project is a rewrite/completion of my other project, "ChessConsole". I aim to write more organized, readable, and perhaps more efficient C++. My goal is to create a chess engine capable of competing against other chess engines. The engine was originally based on "Bitboard Chess Engine" by Code Monkey King, which is where I learned how to create a bitboard chess engine. At this point, it is 99.99% my code and my solutions.
